# 实验记录

## 硬件环境

| 阶段 | 硬件        | 耗时                        |
| :--- | :---------- | :-------------------------- |
| SFT  | 1×A800 80GB | 约 2 小时                   |
| DPO  | 2×A800 80GB | 约 3 小时                   |
| 推理 | 单卡 A10G   | 吞吐约 15 req/s，显存约 8GB |

## SFT 超参

| 参数         | 值                           |
| :----------- | :--------------------------- |
| 底座模型     | Qwen3-8B                     |
| 微调方式     | LoRA (r=8, alpha=16)         |
| 数据集       | 内部多轮客服对话，约 50 万轮 |
| 批次大小     | 128                          |
| 学习率       | 2e-5                         |
| 训练轮数     | 1 epoch                      |
| 优化器       | AdamW                        |
| 调度         | 5% warmup + cosine           |
| 通用数据比例 | 9:1                          |

## DPO 超参

| 参数      | 值                   |
| :-------- | :------------------- |
| 模型      | Qwen3-8B-SFT         |
| 数据集    | 正负例对，约 10 万对 |
| 批次大小  | 32                   |
| 学习率    | 1e-5                 |
| 训练轮数  | 1 epoch              |
| beta      | 0.1                  |
| loss_type | dpo                  |

## 评估结果

| 指标               | SFT  | SFT+DPO     |
| :----------------- | :--- | :---------- |
| 多轮任务完成率     | 68%  | 84.3%       |
| 敏感内容拒答准确率 | 81%  | 92.5%       |
| 推理吞吐           | -    | 约 15 req/s |
| 显存占用           | -    | 约 8GB      |

> 评估在 500 条人工标注测试集上进行。

## 消融实验

| 配置                     | 任务完成率            |
| :----------------------- | :-------------------- |
| SFT only                 | 68%                   |
| SFT + DPO                | 84.3%                 |
| SFT + DPO + 自动负例挖掘 | 84.3%（标注量降 75%） |

## 关键结论

- SFT 让模型具备客服多轮对话基础能力
- DPO 通过正负例偏好学习，显著提升回复自然度与合规性
- 自动负例挖掘在保持指标的前提下，将人工标注量降低 75%
- vLLM + AWQ + FlashAttention 使单卡 A10G 可承载约 15 req/s
