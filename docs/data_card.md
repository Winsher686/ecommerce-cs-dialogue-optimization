# 数据卡（Data Card）

> 本文件由 `python -m src.data.audit` 自动生成，也可手动维护。

## 数据来源

- 电商客服多轮对话日志
- 简历项目中使用模拟数据，字段与线上一致

## 字段说明

每条记录格式：

```json
{
  "messages": [
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ],
  "source": "demo"
}
```



## 正负例构建

- 正例：优秀客服回复 + GPT-4 改写
- 负例：原模型淘汰回答 + 规则增强 + 自动挖掘
- 覆盖边界场景：模糊意图、多意图冲突、口语化表达

## 规模

- 清洗后对话数：见审计报告
- DPO 正负例对：见审计报告

## 敏感信息处理

- 手机号脱敏为 `[PHONE]`
- 身份证脱敏为 `[ID]`
- 邮箱脱敏为 `[EMAIL]`
- 订单号脱敏为 `订单[ORDER]`
